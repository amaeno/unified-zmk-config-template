トラックパッドとトラックボールの操作がもっさりする

状態: 未修正 要調査（実機の操作感）

実機で、トラックパッドとトラックボールの操作に「もっさり感」があります。L4 scroll でのスクロールも効きが悪く感じられます（2026-10-11 の報告）。動きの軸のずれなども含めて、原因はまだ調べていません。別のタスクとして調べます。

調べる候補（どれも未確認。現在値は 設定項目 と ハードウェア › ポインティングデバイス）:

  • トラックボールの報告間隔の下限（PMW3610_ALT_REPORT_INTERVAL_MIN）と解像度（cpi）
  • トラックボールの軸の入れ替え（x-input-code / y-input-code）と向きの反転
  • Bluetooth の接続間隔（右と PC の接続。左右間の接続は右が 7.5 ms に決めていて、左の設定は使われない）
  • トラックパッドの感度（sensitivity。上げると Bluetooth で問題が出るという本家のコメントあり）
  • L4 のスクロール: 長押しの判定時間（既定で約 200 ms）と、1 ノッチに要るカウント数（設定項目 › スクロール）

2026-10-12 の土台固め（タグ fw-2026-10-12 の版）から、左右とも同じ ZMK の版（分割の入力の処理が詰まる不具合の修正 #3110 を含む）を使います。そろえた状態でもっさり感が残るかを確かめてから調べます。

2026-10-12 の調査で分かったこと:

  • ポインタだけでなく、キーとエンコーダも含めて全部の入力が 1 テンポ遅れて見える。
  • 右を USB でつなぐと遅れが消える。同じ Mac に Bluetooth LE でつないだ別のマウス（MX Ergo）は遅れない。原因は、右と Mac の Bluetooth の接続と見ている。
  • ZMK の既定の接続間隔（7.5〜15 ms）は、Apple の規定（HID でも下限 11.25 ms）に合わない。右の要求を 11.25〜15 ms に変えたところ、出だしは速くなった。詳しくは 設定項目 › Bluetooth の接続。
  • それでも、操作を続けると少しずつ遅くなり、手を止めてもカーソルが少し動き続けた（1〜2 秒で戻る）。Bluetooth で送りきれないマウスのレポートが溜まり、キーとエンコーダの処理まで遅れていた。レポートの間引き（16 ms に 1 回まで）と送信出力の引き上げを入れた（ブランチ fix/ble-mac-latency。実機での確認待ち）。詳しくは 設定項目 › 送りきれないレポートが溜まるとき。L4 のスクロールも同じ詰まりが起きうるので、間引きを掛けた。

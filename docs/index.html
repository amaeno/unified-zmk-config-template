双掌 (sosho) カスタマイズ資料

ELEKIT 製の分割キーボード「双掌」の ZMK ファームウェアを、自分用にカスタマイズしていくための資料です。本家への push や PR は行わず、このリポジトリの中だけで完結させます。

このキーボード

構成
44 キーの分割キーボード。左右それぞれに Seeed XIAO nRF52840 を載せる
入力
各半分にロータリーエンコーダ 1 個と、ポインティングデバイス（トラックパッドかトラックボールのどちらか）
左右の役割
右がセントラル（PC と Bluetooth で繋がる側。ZMK Studio もここ）、左がペリフェラル
ファームウェア
ZMK。左右で別々の uf2 を書き込む

やりたいことから探す

やりたいこと手段見る場所
キー割り当てを変える・レイヤーを使い分けるビルド不要 ZMK Studio開発フロー › ビルドが要るか
コンボ・エンコーダ・ポインタの感度を変える要ビルド ファイルを編集開発フロー › ビルドが要るか
ファームウェアをビルドして書き込む./scripts/build-local.sh開発フロー › ビルド・書き込み
新しい機能を足す・不具合を直すトピックブランチで作業する開発フロー › 開発の流れ
ペアリングや左右の接続がおかしいsettings_reset を書き込む開発フロー › 接続がおかしいとき
ビルドが通らない・変更が反映されない症状から探す開発フロー › うまくいかないとき

この資料の仕組み

手書きの説明と、リポジトリ内のファイルから自動生成する部分でできています。自動生成の部分には「自動生成 · 元: …」と元ファイルが書いてあり、手で直しても次の生成で上書きされます。設定やスクリプトを変えたら、次のコマンドで作り直します。

python3 scripts/gen-docs.py

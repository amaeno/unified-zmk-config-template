追加できる機能の候補

このリポジトリで調べて分かったものです。作るときは /add-feature の流れで進めます。

  • &caps_word Studio で割り当て

    次の区切り（スペースなど）まで大文字で打つ機能。この版の ZMK にそのままあり、追加の設定は要りません。区切りとみなさない文字は continue-list で変えられます（変えるときは要ビルド）。

  • トラックボールの速さを切り替える 要ビルド

    トラックボールの解像度（CPI）は、この版のドライバではキー操作で切り替えられません。代わりに、スクロールと同じ仕組み（レイヤー別の input-processors）で、特定のレイヤーのあいだだけ zip_xy_scaler で遅く・速くできます。

  • コンボの誤爆を防ぐ 要ビルド

    コンボには、直前のキー入力から一定時間たっていないと発火しない require-prior-idle-ms、特定のレイヤーだけで有効にする layers、両方のキーを離すまで保つ slow-release があります。速く打ったときにコンボが誤って出るようなら使います。

  • スクロールモードの調整 要ビルド

    0 番の長押しの判定時間（&lt の tapping-term-ms）と、スクロールの速さ・向き。ポインタのもっさり感の調査とあわせて見直します。

  • 実機の割り当てを資料に反映するツール 作業は大きめ

    キー割り当ての正本を Studio にしたので、資料のレイヤー図（ファイルの初期値）と実機はずれていきます。Studio と同じ通信（USB 経由）で本体の割り当てを読み出せれば、レイヤー図を実機に合わせられます。通信の仕様はビルド環境の ZMK のモジュールにあります。

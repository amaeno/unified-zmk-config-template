- 標準 behavior の定義は `.zmk-ref/zmk-app/dts/behaviors/<名前>.dtsi`、binding は `dts/bindings/behaviors/zmk,behavior-<名前>.yaml`、実装は `src/behaviors/behavior_<名前>.c`
- input-processor の定義は `zmk-app/dts/input/processors/*.dtsi`、実装は `zmk-app/src/pointing/input_processor_*.c` と `input_listener.c`、docs は `zmk-docs/keymaps/input-processors/`。コンボは `zmk-app/src/combo.c`、docs は `zmk-docs/{keymaps,config}/combos.md`
- BLE 接続パラメータ/split 通信: 既定値は `zmk-app/Kconfig`(BT_PERIPHERAL_PREF_*)、split は `src/split/bluetooth/Kconfig`、セントラル接続は `central.c`(bt_conn_le_create)、ペリフェラル送信キューは `service.c`、HID 送信は `src/hog.c`。Zephyr 本体のソースは .zmk-ref に無い
- Zephyr 本体は .zmk-ref に無いが Docker ボリューム `sosho-zmk-ws` の `/ws/zephyr` にある（読み取りは `docker run --rm -v sosho-zmk-ws:/ws:ro zmkfirmware/zmk-build-arm:stable bash -c 'grep ...'`）。Pinnacle は `/ws/zephyr/drivers/input/input_pinnacle.c`、binding は `dts/bindings/input/cirque,pinnacle-common.yaml`。EC11 は ZMK 側 `zmk-app/module/drivers/sensor/ec11/`、kscan は `zmk-app/module/drivers/kscan/`、PMW3610 は `.zmk-ref/zmk-pmw3610-driver/{Kconfig,src/pmw3610.c}`
